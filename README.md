# BANG! Dice — Web Game

Bản chơi một người với bot, hỗ trợ bàn 3–8 người. Giao diện tự xếp ghế quanh bàn; máu và mũi tên hiển thị ngay dưới thẻ nhân vật.

## Chạy cục bộ

```bash
npm install
npm run dev
```

## Kiểm tra

```bash
npm test
```

Luật nền, phân phối vai trò và 16 kỹ năng nhân vật bám theo PDF luật gốc do người dùng cung cấp.
